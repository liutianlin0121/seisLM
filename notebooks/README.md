# Historical research notebooks

These notebooks accompany the original research experiments. They may depend on
local datasets, task checkpoints, author-specific paths, or the original Python
environment, and are outside the maintained demo checks.

Start with the [practitioner examples](../README.md#examples) for pretrained
inference and interactive feature visualization. Their public Colab copies load
the released Hugging Face models without a repository clone or private files.

Foreshock/aftershock fine-tuning is under review and is not a recommended demo
in this update. Original pretraining and downstream experiments remain research
workflows; see the [installation guide](../docs/installation.md) for their
dependency boundaries.
